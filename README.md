# Sprint3-Data-Analysis

This project analyzes data from the 2025 Division 1 Women’s Wrestling Top 3 competitors in each weight class. Using Python, Pandas, and Matplotlib, the program reads a CSV file and performs data analysis to answer key questions about team performance.
The program demonstrates data grouping, filtering, sorting, aggregation, and visualization. It calculates total wins, total points scored, and total takedowns by school. It also generates a bar chart to visually compare total wins between schools.

## Instructions for Build and Use

Steps to build and/or run the software:

1.Install Python 3.10 or newer.

2.Install required libraries by running:

      pip install pandas matplotlib

3. Place the dataset file 2025_D1_Womens_Wrestling_Top3_by_Weight.csv in the same directory as the Python script.

4. Run the program using: python filename.py

Instructions for using the software:

1. Run the script in your terminal or IDE.

2.The program will:
-Display the full dataset
-Show total wins by school
-Show total points scored by school
-Filter and display Iowa wrestlers
-Sort wrestlers by weight class
-Show total takedowns by school
3. A bar chart will appear displaying total wins by school.
